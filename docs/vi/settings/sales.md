# Bán hàng

Cấu hình module bán hàng để nhân viên thị trường có thể ghi nhận đơn hàng tại điểm bán trong quá trình thực hiện visit.

## Truy cập

<!-- TODO: screenshot - Menu Cài đặt → Bán hàng -->

Vào **Cài đặt** → **Bán hàng**

## Danh mục sản phẩm

<!-- TODO: screenshot - Danh sách sản phẩm/danh mục -->

**Thêm sản phẩm**:

**Bước 1:** Nhấn **Thêm sản phẩm**

**Bước 2:** Nhập tên, mã sản phẩm, đơn vị tính, giá

**Bước 3:** Nhấn **Lưu**

**Import sản phẩm từ file**: Dùng chức năng Import để thêm nhiều sản phẩm cùng lúc
