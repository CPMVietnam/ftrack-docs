# Cài đặt tài khoản

Cấu hình chính sách bảo mật cho tài khoản người dùng trong hệ thống.

## Truy cập

<!-- TODO: screenshot - Menu Cài đặt → Cài đặt tài khoản -->

Cấu hình yêu cầu đối với mật khẩu người dùng:
- Độ dài tối thiểu
- Yêu cầu ký tự đặc biệt / chữ hoa / số
- Thời hạn hết hạn mật khẩu
