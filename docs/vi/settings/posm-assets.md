# Tài sản/POSM

Cấu hình module quản lý tài sản và vật tư trưng bày (POSM — Point Of Sale Material) tại điểm bán.

## Truy cập

<!-- TODO: screenshot - Menu Cài đặt → Tài sản/POSM -->

Vào **Cài đặt** → **Tài sản/POSM**

## Danh mục tài sản/POSM

<!-- TODO: screenshot - Danh sách các loại tài sản/POSM -->

**Thêm loại tài sản mới**:

**Bước 1:** Nhấn **Thêm loại tài sản**

**Bước 2:** Nhập tên, mã, mô tả và các thuộc tính (kích thước, đơn vị...)

**Bước 3:** Nhấn **Lưu**
