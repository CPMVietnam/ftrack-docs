# Cài đặt hình ảnh

Cấu hình các quy định về hình ảnh mà nhân viên thị trường phải tuân theo khi chụp ảnh trong quá trình thực hiện Survey.

<!-- TODO: screenshot - Menu Cài đặt → Cài đặt hình ảnh -->
