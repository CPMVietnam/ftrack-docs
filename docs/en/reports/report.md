# Report

Export consolidated execution reports in multiple formats and filter configurations.

## Access

<!-- TODO: screenshot - Reports → Report navigation -->

Go to **Reports** → **Report**

## Select Report Type

<!-- TODO: screenshot - List of available report types -->
<!-- TODO: verify - available report types in Ftrack -->

Report types:
- Consolidated execution report
- Report by staff member
- Report by store
- Report by program
- Sales report
- Asset/POSM report

## Configure Filters

<!-- TODO: screenshot - Report parameter configuration form -->

**Step 1:** Select the report type

**Step 2:** Set filter parameters:
- Date range
- Staff / group / region
- Program
- Result status

## Preview the Report

<!-- TODO: screenshot - Report preview before export -->
