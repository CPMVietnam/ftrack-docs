# Store List

View all stores in the system along with visit history and execution statistics.

## Access

<!-- TODO: screenshot - Reports → Store List navigation -->

Go to **Reports** → **Store List**

## View the List

<!-- TODO: screenshot - Store list with visit statistics -->

Each store shows:
- Basic info (name, address, region)
- Number of visits completed
- Most recent visit
- Completion rate

## Filters

<!-- TODO: screenshot - Store list filters -->

Filter by: region, store type, execution status, time period

## View a Store's Visit History

<!-- TODO: screenshot - Store visit history details -->

Click a store to see its full visit history.

## Export Data

<!-- TODO: screenshot - Export Excel button -->

Click **Export Excel** to download the list.
