# Map (Reports)

View field staff execution results on a map from the admin web interface.

## Access

<!-- TODO: screenshot - Reports → Map navigation -->

Go to **Reports** → **Map**

## Overview Map

<!-- TODO: screenshot - Map showing all stores with execution status colors -->

The map shows all stores with color-coded execution status:
- **Green**: Completed
- **Red**: Not done / Overdue
- **Yellow**: In Progress
- **Grey**: Not scheduled today

## Map Filters

<!-- TODO: screenshot - Date, staff, region filters on the map -->

Filter by: date, staff, region, program, status

## View Store Info

<!-- TODO: screenshot - Store info popup when clicking a pin -->

Click a store pin to see: name, assigned staff, status, and visit time.

## Staff Route View

<!-- TODO: screenshot - Map in staff route view mode -->

Switch to **By Staff** mode to see movement routes and Check-In locations throughout the day.
