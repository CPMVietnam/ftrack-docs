# Map

How to use the map feature to view store locations and plan your route.

## Open the Map

<!-- TODO: screenshot - Map tab in the app navigation bar -->

Tap the **Map** tab in the bottom navigation bar

## View Stores on the Map

<!-- TODO: screenshot - Map with color-coded store pins -->

The map shows:
- **Your current location** (blue dot)
- **Stores** on today's Visit Plan (colored pins by status)
- Not started / In progress / Completed

## View Store Details

<!-- TODO: screenshot - Store info popup when tapping a pin -->

Tap a store pin to see details and the **Check In** button.

## Get Directions to a Store

<!-- TODO: screenshot - Get Directions button (opens Google Maps / Apple Maps) -->

Tap **Get Directions** to open a maps app with the route to the store.
