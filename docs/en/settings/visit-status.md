# Visit Status

Configure the possible statuses for a retail visit to classify execution results.

## Access

<!-- TODO: screenshot - Settings → Visit Status navigation -->

Go to **Settings** → **Visit Status**

## Default Statuses

<!-- TODO: screenshot - Default Visit Status list -->
<!-- TODO: verify - built-in statuses in the system -->

The system includes several default statuses:
- **Completed** — staff successfully checked in and out
- **Store Closed** — the store was not open that day
- **Not Accessible** — could not enter the store
- **Refused** — store owner declined the survey

## Add a Custom Status

<!-- TODO: screenshot - Add new status form -->

**Step 1:** Click **Add Status**

**Step 2:** Enter a name and description

**Step 3:** Choose a color and icon (if available)

**Step 4:** Click **Save**
